Beam-Guided Memetic Annealing

An exact-quality TSP solver that runs in milliseconds, not minutes.

Held–Karp finds the true shortest tour, but its table doubles with every city and stops fitting in memory around n ≈ 22. BGMA is a polynomial-time heuristic (about n² in practice). On every instance we checked against Held–Karp, at n = 18, 20 and 22, it found the optimum: 26 of 26, at every effort level, including the cheapest.

Past n = 22 there is nothing exact left to compare with, so every run is measured against a proven 1-tree lower bound instead. The optimum can never be below that bound, so the reported gap is a guarantee, not an estimate.

Effort ladder

Each effort level costs about 3× the previous one and roughly halves the remaining gap to the best tour found. At n = 400 the gap goes +2.21%, +1.13%, +0.59%, +0.12%, 0.00% for low through max. low matches the tuned beam + tunnel at that size (+2.21% vs +2.22%) in 0.73 s instead of 6.4 s.

BGMA is still a heuristic. “Optimal” here means matched on every instance we could verify, not a proof that it always is, and no polynomial-time algorithm is known to guarantee TSP optima. The exact check covers n ≤ 22; beyond that the evidence is the lower bound.
