Foraging + annealing

A population of partial tours carries “flow”. Tubes that reach the same configuration merge, selection is soft and weighted by flow, and the survivors are polished by simulated annealing — including uphill moves and double-bridge “avulsions” that jump the tour to a new course.

The exact optimum is computed by Held–Karp dynamic programming, which needs (n−1)·2^(n−1) states — fine up to n = 22 (≈378 MiB), impossible beyond. For n = 23..30 the right panel instead computes a proven lower bound (1-tree + subgradient ascent); when the heuristic tour meets that bound, the tour is proven optimal without enumerating anything. When it doesn't, the gap shown is an upper bound on the true gap, not a guess.
