Beam-guided memetic annealing

A beam constructs diverse partial tours from several poles, a fast 2-opt/Or-opt screen turns each final into a local optimum, and an elite pool is recombined with edge crossover (ERX). Children are kicked by double-bridge moves or a short simulated anneal, screened again, and only the best few get the expensive full-restart polish. The effort dial scales how many islands, generations, children and polish passes the search spends. The right panel is the Held–Karp optimum for n ≤ 20, and a proven 1-tree lower bound above that.

The hybrid pipeline is: beam islands → fast screen → elite pool → ERX → double-bridge / short anneal → fast screen → selective full-restart polish. The effort dial selects a demo-scaled version of the CLI ladder (`low` → `max`): islands, generations, children, elite pool and polish all grow with the level, but the animation caps long runs so playback stays watchable. The full `--effort` budgets live in `hybrid_effort.js`. Held–Karp needs (n−1)·2^(n−1) states: exact up to n = 20 here, impossible beyond. For n = 21..30 the right panel computes a 1-tree + subgradient lower bound; when the heuristic meets it the tour is proven optimal, otherwise the shown gap is an upper bound on the true gap.
