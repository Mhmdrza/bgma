Beam-guided memetic annealing

The exact optimum in milliseconds. No exponential table.

Held–Karp finds the true shortest tour, but it doubles in cost with every city and cannot run past n ≈ 22. This solver is polynomial (about n² in practice) and matched the Held–Karp optimum on every instance we checked: 26 of 26 at n = 18, 20 and 22, at every effort level. Press run and watch it race the exact answer on the right.

n ≤ 20Right panel is the exact Held–Karp optimum. The tour on the left should land on it, usually in a few milliseconds.
n > 20Held–Karp is out of reach, so we keep going: the right panel becomes a proven 1-tree lower bound. Meet it and the tour is optimal. Miss it and the gap is a guaranteed upper limit.
n = 400In the CLI, xhigh lands within about 1.25% of the proven bound in 20 s (low takes 0.7 s). See the runtime table below.

How: a beam builds diverse partial tours from several poles, a fast 2-opt/Or-opt screen turns each into a local optimum, and an elite pool is recombined with edge crossover (ERX). Children are kicked by double-bridge moves or a short anneal, screened again, and only the best few get the expensive full-restart polish. The effort dial scales how much the search spends.

What “optimal” means here. For n ≤ 20 the page computes the exact optimum with Held–Karp and the tour either equals it or does not; nothing is assumed. Held–Karp needs (n−1)·2^(n−1) states, so it stops there. For n = 21..30 the right panel computes a 1-tree + subgradient lower bound: when the heuristic meets it the tour is proven optimal, otherwise the shown gap is an upper bound on the true gap, not a guess. BGMA is still a heuristic, so “optimal on every instance we checked” is evidence, not a theorem.

Pipeline: beam islands → fast screen → elite pool → ERX → double-bridge / short anneal → fast screen → selective full-restart polish. The effort dial selects a demo-scaled version of the CLI ladder (`low` → `max`); the animation caps long runs so playback stays watchable. The full `--effort` budgets live in `hybrid_effort.js`.
